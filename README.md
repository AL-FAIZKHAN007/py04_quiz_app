# Quiz App
An interactive quiz application built using Python’s Tkinter library. 
This app allows users to test their knowledge across different difficulty levels 
with a simple GUI.
## Features
* GUI-based quiz application
* Three difficulty levels:<br>
 -Easy<br>
 -Medium<br>
 -Hard
* Randomized questions for each playthrough
* Score and percentage calculation
* Performance feedback (as per played)
* Option to restart the quiz
## Requirements
* Python 3
* Tkinter(pre-installed Library)
## How to Run
1. Clone the repository:<br>
git clone https://github.com/AL-FAIZKHAN007/py04_quiz_app.git
2. Navigate to the project directory:<br>
cd py04_quiz_app
3. Run the application:<br>
python3.13 quiz_app.py
## How to Use
1. Launch the app
2. Select a difficulty level
3. Answer multiple-choice questions
4. View your final score and performance
5. Click Play Again to retry
## How It Works
* Questions are stored in a dictionary
* Questions are shuffled randomly using random.shuffle()
* Each correct answer increases the score
* Final score and percentage are displayed at the end
